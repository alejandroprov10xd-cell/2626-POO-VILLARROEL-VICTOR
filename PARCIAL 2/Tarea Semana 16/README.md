# Tarea Semana 16

Esta carpeta contiene la evolucion de `restaurante_app` para trabajar manejo de
eventos en Tkinter aplicado a la gestion de usuarios.

La implementacion principal esta en:

```text
restaurante_app/
```

La version parte de la Semana 15 y conserva login, productos, ventas, datos JSON,
servicios, modelos, interfaz y recursos visuales en `assets/`.

La mejora de Semana 16 agrega CRUD de usuarios con roles `Administrador`,
`Empleado` y `Cliente`, una tabla `Treeview`, eventos `<<TreeviewSelect>>`,
`<Return>`, `<Escape>` y `<<ComboboxSelected>>`, botones con `command=` y
persistencia en `datos/usuarios.json`.

Para ejecutar:

```bash
cd restaurante_app
python main.py
```
